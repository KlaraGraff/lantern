# 词卷

> 今天背的词，出成今天的卷子。

把当天背的单词粘贴进来，AI 生成一份阅读理解 + 语法填空试卷。每道题都有「考点约束」：**不认识目标词就答不出来**——这是它和普通阅读生成器的区别。

## 功能（v1）

- **考点约束出题**：词义决定推断 / 同义替换 / 逻辑信号词三种合格出法，干扰项按「记错词义的人会怎么选」设计。
- **遮词自检**：生成后遮住目标词让模型重做，仍能答对的题判为无效并重出。
- **判分与讲解**：答错的题给中文讲解（点名考点词），每题溯源到原文句子，可跳回原文段落。
- **错词重现**：答错的词 2 天后、7 天后混入新卷重现（卷面不标记），再错则重新计时。
- **难度可选**：CET-4 / CET-6 / 雅思 / 考研。
- **多篇拆分**：词多时按每篇 8–12 词自动拆成多篇文章。
- **多服务商**：Anthropic / DeepSeek / OpenAI / Ollama / LM Studio / 自定义 OpenAI 兼容端点，模型名自由填写，不限 Claude 系列；本地模型（Ollama / LM Studio）免 key。
- **演示模式**：没有 API key 也能用内置样卷体验完整流程（演示卷用内置词表，不写错词池）。

## 使用

```bash
npm install
npm run dev
```

打开设置选服务商并填 API key（浏览器直连，key 只存在本机 localStorage）。默认 Anthropic + Claude Opus 5，可切换到 DeepSeek / OpenAI / 本地 Ollama·LM Studio / 任意 OpenAI 兼容端点，模型名自由填写。出题按钮旁对单价已知的模型显示单次费用估算，未知模型以服务商账单为准。

## 技术

纯前端 SPA（Vite + React + TS），无后端；数据存 IndexedDB（Dexie）。LLM 调用全部走结构化输出。详细决策见 [docs/decisions.md](docs/decisions.md)。

```bash
npm test        # 单元测试（错词调度器、判分、拆词）
npm run build   # 类型检查 + 构建
```
