# 词卷 · 产品与技术决策记录

> 「今天背的词，出成今天的卷子。」
> 本文件记录已拍板的决策及理由。改动任何一条都算范围变更，需重新确认。

## 产品定位（v1）

- **单人自用**：无账号系统，数据全部存在本机浏览器。
- **自带 API key，服务商可选**：设置页选服务商（Anthropic / DeepSeek / OpenAI / Ollama / LM Studio / 自定义端点）并填对应 key，按量付费，无服务器成本。**不限定 Claude 系列模型**——模型名是自由文本，切服务商时预填默认值。
- **手动粘贴词表**：一次粘贴当天背的词，暂不对接背单词 App。

## 核心机制

### 考点约束（本产品的差异化所在）
每道题必须做到：**不认识目标词就答不出来**。合格出法：词义决定推断、同义替换、态度/逻辑信号词；禁止出能靠上下文绕过目标词的题。提示词见 `src/llm/prompts.ts` 的 `EXAM_POINT_RULES`。

### 遮词自检（默认开启）
生成后把目标词遮住，让模型重做一遍。仍能有把握答对的题 = 没考到词，重出一轮（只重出一轮，防止无限循环烧钱；重出失败保留原题）。

### 错词重现（v1 就有）
- 答错 → 入错词池，2 天后重现；重现答对 → 7 天后再现；再答对 → 出池。
- 任何时刻再答错 → 回到 +2 天档，错误次数 +1。
- 重现词混入新卷，**卷面上不做标记**（标记了就等于提示）。

### 溯源
每道阅读题存 段号 + 原文引句，判分页可高亮引句并跳回原文段落。讲解和溯源在**生成时**一并产出并存库，交卷时阅读题本地判分、零等待；只有语法填空的变体拼写需要 LLM 裁决。

## 素材来源（二期预留）

数据模型里 `MaterialSource = 'ai-original' | 'exam-adapted' | 'exam-verbatim'`，v1 一律 `ai-original`。二期：真题改编为主模式（真题骨架 + 植入当日词），真题检索做讲解时的例句库。真题数据由用户收集。**二期不需要改 schema。**

## 技术架构

- **纯前端 SPA，无后端**：Vite + React + TypeScript。单人自用 + 自带 key，没有需要服务器保守的秘密。
- **多服务商双通道**（模式移植自本机 Lantern 项目）：服务商目录在 `src/llm/providers.ts`（`AI_PRESETS`）。Anthropic 走官方 SDK（`dangerouslyAllowBrowser: true`——风险是 key 暴露给页面脚本，本应用无第三方脚本，属正当场景；结构化输出走 `output_config.format` + zod schema，流式防超时）；其余服务商走 OpenAI 兼容接口（JSON Schema 内嵌提示词，`response_format` 仅对确认支持的 OpenAI/DeepSeek 开，解析带 extractJson 兜底）。端点拼接规则：路径末段不是版本号才补 `/v1`。
- **本地模型免 key**：Ollama / LM Studio 判定为本地服务商，不要求填 key。
- **dev server 本机转发**（`vite.config.ts` 的 `llmProxy` 中间件）：第三方中转站普遍不放行浏览器 CORS（预检直接 403），纯前端直连必死。开发服务器下兼容通道统一走同源 `/llm-proxy`，由 vite 在本机代发（Lantern 桌面端后台代发的纯前端对应物）；静态部署没有这层，回退浏览器直连，届时要求服务商自身放行 CORS。
- **IndexedDB（Dexie）** 存试卷、错词池；localStorage 存设置（含 key 与服务商配置，迁移逻辑兼容旧格式）。
- **模型自由填写**，切服务商时预填该服务商默认模型；费用估算只对单价已知的模型给数字（`src/llm/pricing.ts`），未知模型显示「以服务商账单为准」——不编造价格。
- **逐篇并行生成**：每 8–12 词一组各发一次调用（而非一次生成全卷），避免长输出截断；未被任何题考到的词从卷面词表剔除，防止错词池误判「永远到期」。
- **演示模式**：无 key 也能用内置样卷跑完整流程（出题→作答→判分→错词入池），供体验与自动化测试。

## 分工与验收

- 主会话：领域契约（`src/types.ts`）、LLM 服务（`src/llm/`）、集成与提交。
- 子代理 A（UI）：按已批准的样张实现五屏界面。
- 子代理 B（逻辑）：Dexie 存储、错词调度器、判分整合，vitest 单测护住。
- 验收：`npm run build` 绿 + `npm test` 绿 + 五屏对齐样张 + 演示模式全流程可用。
