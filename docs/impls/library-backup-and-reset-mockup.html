书库备份 与 重置全部数据 · 样张

两个都是保护数据的功能。「书库备份」放在 设置 → 书库与同步，「重置全部数据」放在 设置 → 通用 最下面的「危险操作」区。下面把每个状态都画出来：没设置、正常、正在进行、出错、确认步骤。文案都是草稿，可以直接改。

一、书库备份（设置 → 书库与同步）

把书的原文件和封面单向复制到你选的文件夹（移动硬盘、NAS、Dropbox 都行）。只复制新增的，已经在那边的跳过。划线、生词、阅读进度不在备份里——那些靠 iCloud 同步。

二、重置全部数据（设置 → 通用 → 危险操作）

把这台设备上的 Lantern 恢复成刚装好的样子：书、划线、生词、对话、阅读进度、设置和 API Key 全部删掉。两步确认，任何一步取消都不会删任何东西。iCloud 里的那份不删。

删除这台设备上的所有书、笔记、生词、对话、设置和 API Key，恢复到刚安装的样子。
F · 第一步：说清楚会删什么（开着 iCloud 同步时）

重置这台设备上的全部数据？

以下内容会从这台设备上永久删除：

  • 书库里的 128 本书和封面
  • 划线、笔记、书签、生词和复习记录
  • AI 对话和解释记录
  • 所有设置和 API Key
iCloud 同步已开启：重置会先关掉这台设备的同步，iCloud 里的那份不会被删。以后重新打开同步，数据会再下载回来。

想先留一份？可以先去「书库与同步」做一次书库备份。

为什么这样画：入口放在通用的最底部、单独一个「危险操作」区，平时不会误碰；第一步把会删的东西按用户能认出的名字列出来（不写数据库文件名），开着同步时专门说明 iCloud 那份不删；第二步要求输入 RESET（中英文界面都一样），默认焦点在「取消」上。备份和重置互相提一句，但不强制先备份。
