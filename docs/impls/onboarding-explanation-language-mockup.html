三处需要你点头的取舍
  • 模式改了名字。「自适应双语」→「中英对照」，「英文分级」→「全英文」。原来的名字在描述实现，新名字在描述你会看到什么。设置页同步改。
  • 样例是死的还是活的。样张里是写死的一句话（三种模式各一份，中英各一套，跟着界面语言走）。好处是零延迟、零成本、绝对可控；代价是它不反映你实际选的等级——只有「全英文」那条我建议做成按等级取三份预制文案（A1–A2 / B1–B2 / C1–C2）。设置页那个免费本地预览是真调模型的，引导里我不建议那么做：第一屏卡住比什么都劝退。
  • 跳过等于选推荐。点「跳过」时把「中文讲解」和 B1 一起写进设置，而不是留空——留空会走后端兜底，那个兜底是自适应双语，等于跳过的人被塞了一个我们刚判定太难的默认值。
