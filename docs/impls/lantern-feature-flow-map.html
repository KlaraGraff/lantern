图 1 全景：四层结构

整个产品其实是一条单向的沉淀管道：三个入口触发能力层，能力层的产物落进九张表，九张表再从五个出口回到用户眼前。 值得注意的是 MCP 是第二个平级入口——外部 AI 客户端读写的是同一批表，不经过任何前端逻辑。

  • 管道方向是干净的。没有一处出口反向去改能力层的配置，也没有一张表被两个能力同时写。这在这个体量的个人项目里不常见。
  • MCP 是被低估的一层。15 个工具直接读写沉淀层，绕过全部前端逻辑。它意味着「外部 AI 帮我整理生词本」是可行的，但也意味着前端加的任何校验都不是真正的护栏。
  • 阅读统计是一座孤岛。它只读 reading_sessions，AI 复盘的入参白名单里明确排除了笔记、高亮、生词。隐私上是对的，但代价是「这个月读了 12 小时」和「这个月收了 80 个词」永远不会出现在同一句话里。

图 2 一次选中，八个去向

这是「会不会卡手」最该看的一张。选中文字后，系统先按词数把它分成三类，三类各有一套可配置的菜单， 菜单项再分发到八条完全不同的链路。没有一条链路会打断阅读——全部是浮层或侧栏，正文不跳走。

  • 三类分流是这个产品最聪明的一处设计。单词、短语、段落要的东西本来就不一样，用一套 UI 硬撑会两头不讨好。而且分类用的是 Intl.Segmenter 而不是按空格切，中英文都对。
  • 「收藏」的三级降级链（AI 短释义 → 本地词典 → 存空词条）是全应用错误处理的第二个样板：AI 挂了，收藏这个动作本身不会失败。
  • 但配置面积也在这里失控。3 类 × (菜单顺序 + 启用项 + 卡片模块 + 密度 + 宽度) + 6 个自定义动作 + 键位绑定 —— 一个只想「查个词」的用户，要在设置里穿过这一整片才能确认默认值合不合适。
  • 没有批量。这是「卡手」在这张图上唯一的确凿位置，下面图 3 会看到它的后果。

图 3 学习闭环：哪些自动，哪些要手动，哪里断

方针里那句核心闭环——阅读 → 查词 → 追问 → 收藏 → 回显 → 复习 → 回到原文——现在是通的。 橙色实线是系统自动做的，蓝色虚线是必须用户动手的，红色是断口。 看下来会发现：底层数据基本没有断点，断的全在界面上。

  • 闭环确实合上了。从「读到生词」走到「回到原文」，中间只需要用户主动做两件事：点收藏、点复习。其余全自动。这是这个项目最扎实的成果。
  • 跨书掌握度是全应用最深的一层个性化，而且本月刚把它从「用户完全感知不到」变成了卡片上的一行说明。做对了还说出来，这一步很关键。
  • 四处断口的性质完全一致：后端能力已就位，前端没有开口。list_annotations、bulk_update_vocab_mastery 都在命令表里注册着但前端零调用——这不是设计缺陷，是收尾没做完。
  • 断口 ③ 是唯一一个会让整条闭环空转的。前面所有自动化都在往复习队列里灌词，而队列本身没有任何一处会主动出现在用户视野里。

图 4 前置依赖链：「卡手」到底卡在哪

这张图回答的是「实际使用中会不会卡手」。卡手不来自功能太多，来自前置条件不可见。 左边是四个门槛，右边是过不去时各个功能的实际状态。红色是彻底不可用，橙色是静默降级——静默降级比不可用更伤，因为用户不知道自己错过了什么。

  • 门槛 ② 是四个里最贵的。另外三个用户至少知道自己被挡了，② 是产品的核心卖点在静默失效，而用户会把账算到产品头上。
  • 降级策略本身设计得很对。X-Ray 无索引不编、聊天 12 档自动收窄、收藏三级 fallback、TTS 四档音源——每一处的取舍都有道理。问题只在于这些道理没有一处对用户可见。

图 5 界面骨架：面板、作用域、两套导航

功能跑得比容器快，最后都堆在这三处：右侧五个面板走两种机制、阅读设置有四层来源、侧边栏有两套导航模型。 这三处都不产生 bug，但都在持续消耗用户建立心智模型的能力。

  • 这三处都不是 bug，所以永远不会被测试发现，也永远不会被优先级排到前面。但它们是新用户建立心智模型时唯一的成本来源。
  • 面板归并顺带解决了图 3 的断口 ②：「本书痕迹」加一个「高亮」tab，纯划线就有了归宿，书库层再加一个「标注」页对应即可，后端 list_annotations 已经写好在等着。

图 6 数据边界：什么跨设备，什么只在本机

同步是按事件日志走文件目录（可放 iCloud Drive），不是服务端账户。 38 类事件决定了跨设备能看到什么。这里有一处需要产品拍板的取舍：查词历史和阅读统计都不同步。

  • 同步的取舍面几乎处处正确，尤其是「按键白名单而不是按表」这个决定，以及字体身份那个例外——注释里把为什么写清楚了，这是防止后人改回去的正确做法。
  • 但「查词历史 + 阅读统计不同步」是一个产品决策，不是技术结论，而它现在是以技术默认值的形式存在的。这两张表恰好是最近三个功能（历史收藏漏斗、语境复习来源、阅读统计）的地基。
