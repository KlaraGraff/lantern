# 设置信息架构重排(Settings IA Reorg)

- **状态:已批准(2026-08-07,含细化后的「书库」屏),实现中**(样张:`settings-reorg-mockup.html`)
- 2026-08-07 增量裁定:①「进度显示」不用三个开关,改多选胶囊(点亮哪个显示哪个);②各分区行右侧的下拉/按钮控件统一等宽对齐;③ Aa 面板删除 5 组后**不加任何迁移提示链接**——应用尚未分发,没有需要引导的老用户。
- **来源:**用户 2026-08-06 反馈——「现在设置的归类项太多,拆分得也很多,你需要重新归类,每一个项目的排序也要重新设计……现在的设置确实太乱了。」典型例子:界面语言被埋在「通用」中部、翻译语言之上,误设英文后用户找不到改回来的入口。
- **同车改动:**已批准的 Aa 面板分流(5 组「设定一次就不再动」的项从 Aa 面板迁出)在本次重排中一并落位。

## 一、盘点发现的问题

1. **界面语言被埋没。**「通用」的顺序是:显示名称 → 英语学习档案(CEFR、解释语言、翻译语言、考试估算)→ **界面语言** → 其他。找语言设置的人先撞上「翻译语言」,真正的界面语言在一整块学习档案之后。
2. **「外观」整个分区只有 1 行**(主题)。一个顶级导航项就为一个下拉框。
3. **AI 相关设置散落在 4 个分区**:服务配置(模型/凭据)、自动分析(自动调用开关)、通用(解释语言/CEFR——决定 AI 解释长什么样)、阅读辅助(卡片消费 AI 输出)。没有一个分区直接叫「AI」。
4. **两个分区都叫「阅读×」**(阅读偏好 / 阅读辅助),分工从名字上看不出来。
5. **5 组设置两处重复**:阅读模式、单双页、翻页动画、翻页键位、进度显示,同时存在于 设置→阅读偏好(作为默认值)和阅读器 Aa 面板(作为本书实时值)。
6. **顶级分区 10 个、纯平铺**,没有视觉分组。

## 二、新结构(10 → 9 个分区,带导航分组)

导航侧栏分成三段(桌面端也加分组,与移动端 root rows 对齐):

| 段 | 分区 | 变化 |
|---|---|---|
| (无标题) | **通用** | 瘦身:界面语言置顶,吸收「主题」;学习档案迁出 |
| | **阅读**(原「阅读偏好」) | 吸收 自动保存/跳过前言;成为 5 组翻页设置的唯一归宿 |
| | **学习**(新) | 原「英语学习档案」整块 + 查词历史保留期 |
| | **划词与卡片**(原「阅读辅助」) | 仅改名;4 个标签页不动 |
| AI | **AI 服务**(原「服务配置」) | 仅改名;4 个标签页不动 |
| | **自动分析** | 不动(紧跟 AI 服务,账单逻辑保留) |
| 书库 | **书库**(合并「书籍来源」+「书库同步」) | 一个分区、两个块;同步块仍按平台门控 |
| (无标题) | **MCP** | 不动(桌面端) |
| | **关于** | 不动 |

「外观」消失(主题并入通用第 2 行);「学习」新增;来源+同步合并——净减 1 个分区,更重要的是每个分区的名字直接回答「我来这找什么」。

## 三、各分区行序

### 通用(6 行)
1. **界面语言**——置顶。误设外语后,第一个分区第一行就能改回来,这是逃生通道的位置。
2. 主题(应用亮/暗;移动端保留 bottom-sheet 行为)
3. 显示名称
4. 自动检查更新(桌面)
5. 重新查看引导
6. 显示日志(桌面,诊断)

### 阅读(带组标题)
- **排版**:阅读主题(色卡)、字体、自定义字体导入(桌面)、字号、窄屏缩小字号、行距、字符间距、词间距、两端对齐、段落间距、首行缩进、页边距
- **翻页与进度**:阅读模式、单双页、翻页动画、上一页按键、下一页按键、进度显示(多选胶囊,不用三个开关)——「设定一次就不再动」的 5 组;**Aa 面板中的对应控件删除**,此处成为唯一入口(Aa 面板保留 12 组「盯着正文调」的项)
- **行为**:自动保存、首次打开跳过前言(从「通用」迁入——它们是阅读行为)
- **学习辅助**:生词辅助(跳转子页,保留 Aa 面板里的跳转链接)
- 底部:恢复默认设置(危险,确认框)

### 学习(5 行)
学习水平(CEFR)→ 解释语言 → 翻译语言 →(低水平英语警示条,条件展示)→ 考试成绩估算(展开表单+历史)→ 查词历史保留期(查词记录是学习数据,归这里)

### 划词与卡片 / AI 服务 / 自动分析 / MCP / 关于
内容零改动;前两者仅改名。

### 书库(两个块)
- **书籍来源**:现有列表(增删改、恢复内置)
- **书库同步**(平台门控,Windows 隐藏):现有开关、共享文件夹、设备列表、危险操作

## 四、实现要点

- `SettingsView` 枚举:`appearance` 删除、`learning` 新增、`tools→cards?`(id 可保留 `tools` 只改标题,避免无谓迁移)、`librarySync`/`bookSources` 合并为 `library`。**旧 id 全部进 `SECTION_ALIASES` 重定向**(现有机制,OCR 迁移已用过),保证深链/引导卡不断。
- 移动端 `settings-root-rows.ts` 同步重排:core=通用/阅读/学习/划词与卡片;AI=对话模型/语音/自动分析;书库=书库;misc=MCP/关于。原「主题」sheet 行删除(主题在通用内,仍可 sheet 弹出)。
- 设置项的**存储 key 一律不动**——这次只动归类、排序、标题;无数据迁移。
- Aa 面板删除 5 组后**不加迁移提示**(用户 2026-08-07 裁定:应用未分发,不存在需要引导的老用户;参见仓库纪律「no legacy compat code」)。
- i18n:新增 `settings.learning.title`、`settings.library.title`、改名两处 title;组标题若与现有 key 重复则复用。
- 测试:root-rows / aliases 的纯函数如有,补 node:test;其余靠 tsc + 现有套件。

## 五、不做什么

- 不合并「自动分析」进「AI 服务」——它回答「哪些东西会在我不知情时花钱」,和「凭据配置」是两个问题,合并反而埋没账单开关(原注释的理由继续成立)。
- 不动各标签页内部的行序(交互方式/卡片设计等)——本次只治顶层迷路问题,页内微调另起。
- 不做设置搜索——分区治好后再评估是否还需要。
