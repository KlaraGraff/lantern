# P2.5 — 整书连续朗读

Status: approved and implemented.

## 已确认产品形态

- 采用顶部工具栏展开式播放器。
- 点击阅读工具栏的朗读入口后，在标题栏下方展开完整控制层；控制层参与布局，不覆盖正文。
- 收起后在标题栏保留“朗读中 / 当前语速”状态胶囊，可重新展开。
- 支持上一句、下一句、暂停/继续、停止、语速、中英语言自动切换、自动翻页、跨段和跨章节连续朗读。
- 对应已确认样张：reader-p2-read-aloud-toolbar-mockup.html。

## 本阶段明确不做

### 现有句子/段落朗读标记统一

连续朗读使用样张中确认的新朗读位置样式，但本阶段不改动从选区或上下文菜单启动的现有句子/段落朗读标记。

这是一个延后到真实效果演示通过后的独立产品板块，届时需要一起对齐：

1. 现有句子、段落朗读是否统一采用连续朗读的当前句样式；
2. “正文标记”设置中的独立朗读标记配置是否保留、合并或改变含义；
3. 设置页标记预览、阅读正文渲染和各阅读主题下的可见性；
4. 选区朗读、连续朗读和暂停位置是否使用同一套状态语义。

在该板块再次获得产品确认前，不得把现有可配置朗读标记直接替换成连续朗读样式。
