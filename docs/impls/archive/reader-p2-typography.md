# P2.3 阅读排版增强

Status: approved and implemented.

## 已确认的产品规则

- 仅可重排文字书籍（EPUB、TXT）提供三项控制：两端对齐、段落间距、首行缩进；PDF 和固定版式不显示。
- 两端对齐开启后，英文等有语言标记的拉丁文字使用浏览器原生断词（`hyphens: auto`）；中文维持浏览器的正常断行规则。不暴露独立的断词开关。
- 段落间距提供“无、紧凑、舒适、宽松”四档。未主动选择档位时保留出版社原始间距。
- 首行缩进根据内容语言取值（中文 2em，其他语言 1.5em），并跳过标题、居中段、图片段、引用和预格式化内容。
- 新设置的默认值必须不改变已导入书籍的原始对齐、段距和缩进；用户主动开启或选择后才覆盖对应出版社样式。

## 数据与渲染边界

- 三项同时拥有全局默认和每书覆盖：阅读设置面板的修改写入该书覆盖，设置页的修改写入全局默认；无覆盖的书跟随全局。
- `paragraphSpacing` 额外有内部值 `original`，用于表达“仍使用出版社样式”，不作为用户可选的增强档位。
- EPUB 通过 Foliate renderer 的注入 CSS 生效；TXT 通过 `TextBookReader` 的内联排版样式及段落 class 生效。
- CSS 只定位普通 `p`，显式排除标题、居中、媒体、引用和预格式化结构；不清除书籍的其他出版方样式。
- Safari 15.1 不支持 `:has()`；正文 document 加载时先给含媒体的段落加内部 class，CSS 再据此排除，避免整组选择器在旧 WebKit 中失效。
- EPUB 在 `view.open()` 后读取 `book.rendition.layout`。`pre-paginated` 固定版式关闭重排、连续滚动和双页设置能力；能力状态按当前书绑定，更新 UI 时不重新打开 Reader。

## 测试

- 设置合并：全局默认、每书覆盖、`original` 的回退。
- 主题 CSS：默认不生成排版覆盖；开启后的对齐、语言断词、段距和智能缩进选择器。
- 能力：普通 EPUB、固定版式 EPUB、PDF 与 TXT 的排版/滚动/缩放边界互不误判。
- TXT：与 EPUB 相同的三项视觉规则。

## 非目标

- 不增加自定义断词算法、语言手动选择或极端数值滑杆。
- 不改变 PDF 或固定版式的排版。
- 不做“一键忽略出版社 CSS”。
