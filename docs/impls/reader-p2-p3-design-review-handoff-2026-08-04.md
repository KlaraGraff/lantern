# Lantern 阅读体验 P2–P3.4 设计复核交接

日期：2026-08-04

用途：交给独立 AI 或工程师复核正式实现是否忠于已确认样板，并审查代码质量、优化空间与潜在缺陷。

当前代码基线：`main` / `03d8b4b`。当前最新发布标签：`v2.8.4`。

## 1. 复核结论不能预设

P2.1–P2.5 与 P3.1–P3.4 已实现、提交并完成过一次自动化与后台视觉验收，但现有记录不能替代独立复核。复核者必须同时检查：

1. 正式界面是否仍符合用户确认的视觉样板和整体基调；
2. 关键交互、异常状态、窄窗退化和 EPUB/PDF 能力边界是否正确；
3. 多个功能同时存在于同一个 Reader 时是否互相覆盖、抢占空间或破坏导航；
4. 代码是否存在可证明的 bug、生命周期竞态、数据一致性风险或明显的过度复杂度；
5. 自动化测试是否覆盖真实风险，而不是只覆盖纯函数的理想路径。

复核应以当前代码和实际运行证据为准，不得因为文档写着“已实现”就直接判定通过。

## 2. Lantern 的统一视觉基调

所有版面必须像同一个安静、专注、带书卷感的桌面阅读器，而不是营销网站、社交产品或卡片堆叠式仪表盘。

### 2.1 必须保持

- **内容优先。** 正文、书籍和阅读事实是第一视觉层级，工具栏、提示和状态退居其次。
- **克制的中性色。** 以白色、浅灰和温和纸张色作为主要表面；紫色只用于选中态、关键动作和少量数据强调，不能让整个页面变成紫色主题。
- **阅读与工具字体分工。** 正文、书名、特色数字和叙述性统计允许使用衬线字体；按钮、标签、设置和说明使用清晰的无衬线字体。
- **扁平而有层次。** 优先使用分隔线、轻边框、留白和极弱阴影组织信息；只在真正独立的条目、弹窗和工具中使用卡片。
- **紧凑但不拥挤。** 控件尺寸适合重复操作，标题大小服从所在区域，不在紧凑面板里使用宣传页级的大字。
- **图标承担工具动作。** 下载、关闭、返回、搜索、播放等使用熟悉图标并提供 tooltip/无障碍名称；避免可以用图标表达时再放一个笨重文字按钮。
- **布局稳定。** 工具条、计数、切换器和列表有稳定尺寸；内容变化、加载状态和 hover 不应推动正文或让控件跳动。
- **面板参与布局。** 页边笔记、人物卡和连续朗读播放器不能遮住正文；除真正的模态任务外，不叠加弹窗或浮层。
- **关键区域固定、数据内部滚动。** 选择器的搜索/批量操作固定顶部，确认操作固定底部，中间列表独立滚动，任何数据都不能穿透或重叠固定区域。
- **完整状态。** 加载、空态、成功、失败、重试、危险确认、不可用能力和窄窗状态都应像正式产品，而不是临时占位符。
- **双语一致。** 中英文信息含义、层级和操作必须对等；不能依赖硬编码文案。

### 2.2 应判为偏离

- 大面积紫色、渐变、装饰光斑或过度品牌化背景；
- 页面区块全部做成悬浮卡片，或者卡片里继续嵌套卡片；
- 右侧面板之上再叠设置弹窗、确认弹窗和选择弹窗；
- 工具栏塞入大量常驻文字按钮，正文反而成为背景；
- 为了“灵动”而加入不可解释、不可复算或会制造焦虑的数据；
- 窄窗直接挤压正文、遮挡内容或让按钮文字溢出；
- 用静态样板中的注释条、方案切换条或演示标签当成正式产品 UI。

## 4. 各板块最终产品决策

### P2.1 当前书结构化导出

- 入口位于阅读页高亮和生词面板工具行，使用无边框 `Download` 图标，不使用笨重的常驻“导出”文字按钮。
- 两个入口打开同一个模态框；默认选择高亮 + 生词、Markdown。
- 支持 Markdown、通用 CSV、Anki CSV；Anki 只导出生词。
- 保存前预览前两条记录；空态、生成中、保存中、成功、失败均需覆盖。
- 本地生成，不调用 AI，不重新编造章节、上下文或解释。
- 路径和同名覆盖由系统保存框处理，不再叠一层确认。

### P2.2 生词语境复习

- 使用原句挖空，而不是先显示单词和释义。
- 提示顺序固定为：**播放读音 → 显示已保存中文句意 → 显示答案**。
- 不显示“还有几个字母”、首字母、字母数或能泄露拼写长度的下划线。
- 可以显示 `3 / 12` 这类复习进度，但不要把“还有几个单词”做成答案提示或主视觉文案。
- 无可用语境时退回普通单词卡；复习阶段不调用 AI 临时生成句意。

### P2.3 阅读排版

- 仅可重排 EPUB/TXT 显示两端对齐、段距和首行缩进；PDF/固定版式隐藏或禁用。
- 两端对齐按语言自动断词，不再暴露独立断词开关。
- 段距为无、紧凑、舒适、宽松四档。
- 首行缩进按语言和段落类型适配，跳过标题、居中段、图片、引用和预格式化内容。
- 默认保留出版社样式，只有用户主动设置才覆盖。

### P2.4 每书设置与全局设置

- 每个覆盖项必须明确显示“本书单独设置 · 恢复全局/跟随全局”，恢复入口不能隐藏。
- 所有管理操作在同一个右侧设置面板内换页完成，不能在面板上再叠一个弹窗。
- 支持全部恢复、提升为全局默认、以及额外选择其他书同时跟随新全局值。
- 选择其他书时只列出存在冲突的书，默认保留其他书自己的设置。
- 候选达到 6 本时出现搜索与当前结果全选；选择跨搜索保持。
- 搜索/全选固定顶部，确认选择固定底部，中间数据独立滚动且不能重叠。
- 提升、覆盖清理、同步 tombstone 必须保持原子性；失败不能留下半成功状态。

### P2.5 整书连续朗读

- 采用标题栏下方的顶部展开式播放器，播放器参与页面布局，不遮正文。
- 可收成标题栏中的“朗读中 / 当前语速”胶囊，之后可以重新展开。
- 支持上一句、下一句、暂停/继续、停止、语速、中英声音自动切换、自动翻页、跨段和跨章节。
- 本轮**不统一**已有选区句子/段落朗读的正文标记样式；该项等真实演示确认后再单独设计，并需连同“正文标记”设置一起处理。

### P3.1 私人阅读统计

- 同一入口包含“阅读历程 / 阅读日历”两个视图，默认阅读历程。
- 两个视图共用时间范围、书籍筛选和总览；视图切换器位于顶部工具组最右侧。
- 阅读统计保持私人，不做排行、社交、连续打卡压力或历史数据猜测回填。
- 闲置 5 分钟暂停；少于 30 秒的会话丢弃。
- 展示可复算事实：有效时长、读过/读完的整数书数、按时长排序的书籍等；禁止“读了 6.7 本”这类不可解释指标。
- 个性化句子采用“本地确定事实 + AI 叙述”。AI 不能重新计算或发明事实。
- AI 必须主动生成/刷新；首次显示服务商、模型、发送字段、额度/费用提示和 AI 标识。
- 默认不发送正文、高亮原文、笔记正文、CFI、精确时间线或未读内容；失败保留旧缓存。
- 字体优先级：本机 Inter/PingFang SC/Georgia/Songti SC，Libre Baskerville 作小型拉丁衬线兜底。
- 完整中文衬线字体通过“增强字体显示”可选下载；显示准确体积、进度、失败降级、关闭保留和移除确认，设备本地保存且不跨设备同步。

### P3.2 页边笔记轨

- 采用页边笔记轨，不采用普通右侧笔记列表。
- 笔记与引用正文位置清晰对应，参与 Reader 布局，不能遮正文或互相重叠。
- 支持加载、空态、新建、编辑、自动保存/保存反馈、失败保留草稿、删除确认、全文列表/搜索、定位引用和返回。
- 窄窗退化为正文下方固定工作区，不能把正文压到不可读宽度。
- 与 AI、书签、生词和人物卡等 Reader 工作区互斥。

### P3.3 被动生词注释

- “词上小字”和“页边释义”两种方式都保留，由用户自行选择。
- 主设置提供总开关、样式和低/中/高密度。
- 阅读页提供快捷开关，但控制的是同一个全局状态；不出现“本书/全局”选择，也不能写进 per-book override。
- 只使用已保存生词，不在阅读过程中调用 AI。
- 仅可重排 EPUB 可用；PDF/固定版式禁用。窄窗自动退化为词上小字。
- 注入标记必须保持 CFI、选区、高亮、跳转和保存位置稳定。

### P3.4 人物/术语卡

- 正式方案为正文就地轻量卡，入口来自选择菜单或阅读工具栏。
- 卡片包含人物摘要、术语解释、关系路径和此前出场位置。
- 默认硬限制到当前阅读位置，宁可少给信息也不能读取后文剧透。
- 整书范围必须在当前卡片内明确确认；关闭卡片即恢复安全范围，整书结果不能污染安全缓存。
- 出场跳转复用统一返回历史；只有跳转真正成功才关闭卡片，失败时保留结果并给出错误状态。
- 窄窗卡片进入正文之后的顺序流，不覆盖正文。
- v1 复用全文检索聚合上下文，不引入向量库。
- 旧右侧索引面板只保留为未来回退方案。

## 5. 跨功能必须一起复核的关系

- P2.3 排版设置是否正确参与 P2.4 全局/每书合并、恢复和提升。
- P3.3 全局生词辅助是否绝不进入 P2.4 每书覆盖。
- P3.2/P3.4/AI/书签/生词工作区是否严格互斥，关闭和返回是否恢复原布局。
- P2.5 自动翻页和跨章节是否污染统一跳转历史，是否破坏脚注、高亮和当前阅读位置。
- P3.1 计时在失焦、闲置、睡眠/唤醒、切书和退出 Reader 时是否重复计时或丢失。
- P3.1/P3.4 的 AI 请求是否严格使用白名单数据，失败或额度不足时是否保留原有本地结果。
- EPUB、固定版式 EPUB、PDF 和 TXT 的能力开关是否一致，隐藏与禁用文案是否清晰。
- 所有新增界面是否同时覆盖中英文、键盘、焦点、屏幕阅读器、减少动态效果和错误恢复。
- P0/P1 的开书、脚注、全文搜索、返回历史、进度显示和翻页不能回归。

## 6. 代码审查重点

### 6.1 高风险共享热点

- `src/pages/Reader.tsx`
- `src/components/ReaderSettings.tsx`
- `src/components/settings/ReadingSettings.tsx`
- `src/pages/reader/useReaderSettingsSync.ts`
- `src/pages/reader/useFoliateAnnotations.ts`
- `src/pages/reader/useFoliateView.ts`
- `src/pages/reader/useReaderNavigation.ts`
- `src/pages/reader/foliate-types.ts`
- `src/i18n/en.json` / `src/i18n/zh.json`
- `src-tauri/src/commands/settings.rs`
- `src-tauri/src/commands/reading_stats.rs`
- `src-tauri/src/commands/enhanced_fonts.rs`
- `src-tauri/src/commands/ai/xray.rs`
- `src-tauri/src/sync/`

### 6.2 重点找什么

- React effect/callback 依赖不稳定导致 Reader 重建、重复监听、重复请求或重复计时；
- 打开/关闭书、切书、组件卸载时异步任务晚到并写入旧状态；
- Foliate document 尚未 ready、已销毁或章节切换期间继续访问 DOM；
- 注释包装重复注入、无法完全清理、破坏 CFI 或造成布局抖动；
- 防抖设置写入与恢复/提升操作竞态，旧 timer 把已删除 override 写回来；
- Rust 事务、同步 outbox、tombstone 和本地 UI 状态不一致；
- 连续朗读跨章节时语句边界、语言切换、停止/暂停和资源清理错误；
- 阅读统计在多入口活动、睡眠时钟跳变和崩溃恢复时重复累计；
- AI 白名单在序列化、日志、缓存键或错误诊断中泄漏正文/笔记；
- 增强字体下载缺少长度限制、校验和、临时文件清理或原子替换；
- 导出 CSV/Markdown 的转义、超大数据、取消保存和敏感内容日志；
- 中英文 key 漂移、硬编码文案、焦点陷阱、不可达按钮和窄窗溢出；
- 大型组件中可以用现有 helper 消除的真实重复，但不要为了“更优雅”制造新抽象。
