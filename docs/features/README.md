# Feature Specs

Specs for features that are in progress or planned. Shipped, dropped, or superseded specs are moved to [`archive/`](archive/). Bug and feature tracking lives in [GitHub Issues](https://github.com/KlaraGraff/lantern/issues).

A spec's number is its issue number here. A `q` prefix marks a number inherited from Quill, the upstream project this was renamed from — its `GitHub issue:` link still points there. Lantern's own issue counter runs over the same range, so the prefix is what keeps `q12` (Quill's auto-update) from colliding with `12` (this repo's reader-settings layering).
