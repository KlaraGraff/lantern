# 小红书 · 第一条 —— 「别再复制粘贴到聊天框了」

母题就是 README 第一节，不另外发明：

> **你早就在用 AI 读书了，只是方式很别扭。**

落点是[推广方案](launch-plan.md)里那句已经定死的定位：**把 AI 放进书里，而不是把书搬进聊天窗口。**

**这条打的是谁**：已经在用 AI 读英文书的人。不是「读不下去原著」的人——那批人还没开始用 AI，把内容拉过去既拧了定位，转化也差（他们配不了 API Key）。选中已经在用 AI 的人，Key 那道门槛自动不存在。

**图文骨架照 README 的节走，一节一张图。** 一条内容只讲一个主张，功能是这个主张的证据，不是并列的卖点。

## 正文

> 读英文原著卡住的时候，我们都在干同一件事：复制那句话，切到聊天窗口，粘进去。
>
> 然后拿到一段更长、更难的英文。切回来，还得重新找刚才读到哪。
>
> 问题不在 AI 笨。是它什么都不知道——不知道你在读哪本书、读到第几章、这一句前后写了什么，也不知道你的英语什么水平、你以前问过什么。这些你每次都得从头交代，于是你干脆不交代了。
>
> 所以我做了 Lantern，一个把 AI 放进书里的桌面阅读器，而不是把书搬进聊天窗口。
>
> 那些你懒得每次交代的事，它一开始就知道：
>
> 📖 你的英语水平——填 CEFR，或者填雅思、托福、四六级成绩让它自己换算
> 📖 你读到第几页——**默认不拿你还没读到的地方回答你**
> 📖 在读哪本哪章——认得出人名和前情，不用每次说「这是《XX》里的」
> 📖 选中处前后——先定住这个词在这里的意思，而不是罗列义项让你自己挑
> 📖 整本书——答案是从书里检索出来的，不靠模型对这本书的记忆
>
> 还有一件聊天窗口做不到的事：**它说的每一句都能点回原文。** 回答里带角标，点一下书就翻到那一句，落点还会闪一下。不是一个悬空的答案，是一个能带你回到书里的答案。
>
> 读一阵之后它会长出更多东西——你读到过又没查的词，它自己记着；这本书里的词你认识多少，本机算得出来。这些都要时间，装完当天没有，它也不会给你摆一个猜出来的数。
>
> ⚠️ 三件事说在下载之前：
> · 它不带 AI 服务，要自己配一个 API Key（你要是已经在用 AI 读书，这一步你早就会了）
> · 只有 macOS（Apple Silicon）和 Windows 11，iPad 和手机用不了
> · 免费，开源，代码都在 GitHub 上
>
> 主页有链接。评论区问什么我都答。
