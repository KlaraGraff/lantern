# 即刻 / X / V2EX —— 「做的过程」

对应[推广方案](launch-plan.md)选题 1。**这条原本是给抖音写的视频脚本，改成文字发在技术场。**

**为什么挪走。** 「一个人 + AI 做出完整产品」是个跑得动的叙事，但它够到的是想学做软件的人，不是想读英文书的人。抖音那个位置要留给[真正的目标人群](post-douyin-in-the-book.md)。这条在即刻、X、V2EX 才是加分项——那里的人跨得过 API Key 那道门槛，还会帮你写教程。

**同一件事在两批人面前是两个意思**：对技术人群「用 AI 写的」是加分，对学习人群这句话只引起质量怀疑。所以这条内容不出现在小红书和抖音，那两条也不提这件事。

**发布前提**：正式版已发、能双击安装。**不出现版本号。**

## 正文

> 五个月前我开始写一个英文阅读器，今天开源了。
>
> 起因很蠢。我读英文原著，遇到看不懂的就复制粘贴到聊天窗口。它不知道我在读哪本书、读到第几章、这一句前后写了什么，也不知道我的英语什么水平，于是按母语者的口径回答我。切回来还得重新找刚才读到哪——而那个答案是悬空的，想核对原文只能自己翻。
>
> 所以我想要一个反过来的东西：**把 AI 放进书里，而不是把书搬进聊天窗口。**
>
> 那些我懒得每次交代的事，它一开始就知道：我的 CEFR 等级、读到百分之几、在读哪本哪章、选中处前后几段、以及从我过去的查词和追问里总结出的「我想要什么样的解释」。全文建了索引，配了 embedding 再叠一层语义检索，答案是从书里检索出来的，不靠模型对这本书的记忆。
>
> 最花时间的是引用。做这件事最好的产品是 NotebookLM，但它的引用只能跳到侧栏里的一段文本——**这东西本身就是阅读器，引用跳回的是书里真正的那一页那一句**，落点还会闪一下。EPUB 拿原文片段在对应章节精确搜索，失败退到备用片段再退到章节开头。
>
> 还有一条我自己最在意的规矩：**默认不拿你还没读到的地方回答你。** 提前知道后面发生了什么，你本来会自己琢磨出来的东西就没机会出现了。想要完整答案，点一下「结合全书重新回答」。
>
> 五个月，1045 次提交，19 万行（前端 7.6 万 TS/TSX + Rust 11.2 万，不含翻译文件和 vendor 目录）。AI 能写代码，但它不会替你决定这软件该长什么样——那部分是一遍遍改出来的。
>
> Tauri 2 + Rust + SQLite，React 19 + TypeScript，foliate-js。MIT。macOS（Apple Silicon）/ Windows 11。本地优先，要自己配 AI 服务，密钥不出这台机器。

技术场可以多给一句 MCP：内置一个 MCP 服务器，打开之后 Claude Code、Codex 能直接读书库、生词本和阅读状态，**写权限是单独的开关，默认关着**。这句在小红书和抖音是无效信息，在这里是最容易被转发的一句。

## 那三个数字是真的

| 数字 | 出处 | 复算 |
| --- | --- | --- |
| 5 个月 | 首次提交 2026-03-06 | `git log --reverse --format=%ad --date=short \| head -1` |
| 1045 次提交 | 截至 2026-08-10 | `git rev-list --count HEAD` |
| 19 万行 | 前端 7.6 万（TS/TSX）+ Rust 11.2 万 | `git ls-files 'src/**/*.ts*' 'src-tauri/src/**/*.rs' \| xargs wc -l` |

**发之前重跑一遍，用当天的数字。** 这类内容的可信度全靠数字经得起问——评论区一定会有人问「多少行」「怎么算的」，答不上来比不发还糟。19 万行不含翻译文件和 vendor 目录，被问就这么说。

## 两条必须守的

**开场那句自我介绍别往「完全不会写代码」那边靠。** 那是这类内容最常见的翻车点——评论区第一个问题就是让你解释一段代码。真实的说法反而更耐打：不是科班出身，靠这个项目自学。

**配图用真实截图。** 这批人一眼看得出生成的界面。八张样张里 `hero.png`、`citations.png`、`context.png` 是这条最该配的三张，规矩和[镜头清单](../guide/screenshots.md)那份一样：公版书、不露 Key、不露绝对路径。**MCP 那条只说不配图**——它的说服力在终端里，而终端拍不出来（见镜头清单），配一张设置页反而把「外部 AI 真的读到了数据」降级成「有个开关」。

## 不要写的

- ❌ 版本号。
- ❌ `xattr` 命令，或任何「系统会拦一下」的说法。
- ❌ 承诺 iOS。
- ❌ 「一天做完」「零基础三天上线」这类夸张——五个月一千次提交本身就是这条最有说服力的部分，把它压缩成三天等于把唯一的可信度扔了。
