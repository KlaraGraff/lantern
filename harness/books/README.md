# 样张用的公版书

README 里的八张图不是画出来的，是用真实的 Lantern 前端跑出来的（`npm run smoke`，
见 `harness/README.md`）。前端是真的，组件是真的，foliate-js 是真的；唯一由我们控制
的是**书的内容**——所以书必须是公版书，否则截图不能公开发。

`.epub` 文件不进仓库（体积大，且随时可重新下载）。从中抽出的封面图会另外提交。

## 下载来源

**https://standardebooks.org** —— 一站解决三件事：

- 全部是美国境内的公有领域作品，电子书本身以 CC0 释出，可以随便用；
- 封面用的是公版画作，而且**已经嵌在 EPUB 里**，不用另外找图；
- 排版是人工校对过的，正文干净，截图上不会出现乱码或垃圾字符。

（Project Gutenberg 也是公版，但大多数书没有封面，正文里还带样板声明，不适合上图。）

**译作要注意**：公版的是原著，不等于译本也公版。下面清单里只有《Meditations》是译作，
Standard Ebooks 用的是 George Long 的公版译本，直接从那里下就没问题。

## 清单

下载后把 `.epub` 原样丢进这个目录即可，文件名不用改。

### 正文会被真实渲染（必需）

| 书 | 作者 | 年份 | 用在哪 |
|---|---|---|---|
| Pride and Prejudice | Jane Austen | 1813 | 主角书。第 1、2、3、4、6 张图的正文、查词、对话、引用都出自它 |
| Emma | Jane Austen | 1815 | 第 5 张图的掌握度时间线会引用「你在《Emma》里查过这个词」，所以它得真的在书架上 |

### 只需要封面和书名（填满书架、支撑难度对比）

难度从易到难排，这样第 6 张图里「这本书比你读过的书难」才有真实的参照物，而不是我编一个平均值。

| 书 | 作者 | 年份 | 档位 |
|---|---|---|---|
| Alice's Adventures in Wonderland | Lewis Carroll | 1865 | 易 |
| The Wind in the Willows | Kenneth Grahame | 1908 | 易 |
| The Adventures of Tom Sawyer | Mark Twain | 1876 | 易 |
| The Great Gatsby | F. Scott Fitzgerald | 1925 | 中 |
| Jane Eyre | Charlotte Brontë | 1847 | 中 |
| The Picture of Dorian Gray | Oscar Wilde | 1890 | 中 |
| Dracula | Bram Stoker | 1897 | 中 |
| Heart of Darkness | Joseph Conrad | 1899 | 难 |
| Moby-Dick | Herman Melville | 1851 | 难 |
| Meditations | Marcus Aurelius（George Long 译） | 1862 译本 | 难 |

十二本，书架排成 4×3 或 6×2 都不空。

如果哪本在 Standard Ebooks 上找不到，跳过就行，少一两本不影响——只有前两本是必需的。
